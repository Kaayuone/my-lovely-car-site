# my-lovely-car-site

Страницы приложения My Lovely Car на GitHub Pages:
<https://kaayuone.github.io/my-lovely-car-site/>.

- `privacy-policy.html` — политика конфиденциальности, ссылка на неё стоит в Play Console и в
  приложении. Это копия: источник — `docs/product/privacy-policy.html` в репозитории приложения,
  правится там и копируется сюда без изменений.
- `index.html` — короткая страница приложения со ссылкой на политику.
- `.nojekyll` — GitHub Pages отдаёт файлы как есть, без обработки Jekyll.
